# H1 对照实验预登记（Phase 3）

> 状态：实验前锁定。本文必须早于任何 H1 在线对照运行提交；变更须另开预登记版本，不能追溯修改本版本的判定阈值。

## 1. 假设与候选定义

PLAN.md §1.2(d) 的原始假设为：

> **H1**：在明确的中文研究场景下，少量稳定、授权清晰的来源 + 统一证据结构 + 可测量的检索质量，即可形成差异化——以来源质量与证据规范取胜，而非平台覆盖数量。

本次操作化：在固定的中文研究题中，启用一个 **Python 官方中文文档适配器**，与纯 Web 基线比较。候选严格定义为：`docs.python.org` 下的 **`/zh-cn/` 路径**；适配器通过该语言路径下的版本化 `objects.inv` 与本地 `searchindex.js` 索引匹配，确定 URL 后定向抓取。它不以通用 Web 搜索作为候选发现机制。

同域名但非 `/zh-cn/` 的页面不计为适配器命中，也不计入本次对照样本。适配器只产出既有 `Evidence` 契约允许的证据，且证据均标注 `source_type=official`、`url`、严格原文 `quote` 与 `fetched_at`。

## 2. 样本与实验单元

有效样本锁定为 **N=8**（均为在线题）：

`fact_freethread`、`noanswer_pep`、`fact_gil`、`fact_venv`、`compare_logging_print`、`timely_maint`、`timely_status`、`noanswer_ml`。

纳入依据是 `run_20260907_010146.json` 中实际存在 `https://docs.python.org/zh-cn/` 证据。`conflict_ft`、`timely_latest`、`fact_asyncio_gather` 虽命中同一官方域名，但仅命中非中文路径，明确排除；离线固定材料题也明确排除。

N=8 已知小于 10。本次结论上限为**不确定/定性观察**，不做“改善”或“收缩”的显著性宣称；仅报告逐题效应量与差异表，不进行显著性检验。第 4 节的机械规则只用于描述方向，不能突破此前述结论上限。

## 3. 指标与标注口径

主指标：

1. **断言引用支持率（严格 quote-only）**：沿用 Phase 2 终审定版的口径，逐条关键事实断言只依据其绑定 Evidence 的 `quote` 判定；`support=1`、`partial=0.5`、`not_support=0`，并报告三档原始分布。不得使用 reader `point` 补足 quote。Phase 2 可比锚点为严格终审 `100.5/122 = 0.8238`，但本实验以这 8 题的两组配对结果比较，不把全体历史分数当作实验组。
2. **答案覆盖率**：按 `questions.py` 预先定义的必答要点评分，`covered=1`、`partial=0.5`、未覆盖或无答案为 `0`；以全部 8 题为分母报告，不按模型临时生成的子问题计分。

辅助指标：每题相关证据命中数、证据获取成功率、成本（LLM tokens、搜索 credits 与可得的其他费用字段）、端到端耗时；另报告任务终态与失败率。失败任务在其不适用的断言支持率分母中标 N/A，但仍保留在全部题的覆盖率、获取成功率、成本与失败率报告中。

沿用 Phase 2 F4 双轮标注：pass 1 为宽口径（报告全文、quote、point 可见）；pass 2 为严格 quote-only（隐藏策略标签与 point，对否定性、穷尽性、数字类从严）。分歧单列；定版比较仅取严格口径。

## 4. 预先锁定的判定规则

以“适配器组 − 纯 Web 组”的百分点差计算两个主指标。成本未显著劣化定义为：适配器组每题平均搜索 credits 不高于纯 Web 组的 120%，且每题平均 LLM tokens 不高于纯 Web 组的 120%；任何成本未知行单列，不计作零成本。

- 判定按以下优先级机械执行，防止阈值边界重叠：先判**收缩方向**，再判**改善方向**，其余均为**不确定方向**。
- **收缩方向**：任一主指标下降至少 5 个百分点。
- **改善方向**：未触发收缩时，任一主指标提升至少 5 个百分点，另一主指标下降不超过 2 个百分点，且满足上述成本条件。
- **不确定方向**：未触发前两项时；特别是两个主指标变化均在 ±5 个百分点内，或成本未知/未满足改善条件的结果，均不能归入改善方向。

由于 N=8，上述结果只能被表述为“方向性/定性观察”或“不确定”，不能作为改善或收缩的统计证明，也不能据此作显著性宣称。

## 5. 公平性约束与执行记录

两组必须使用：同题、同一 glm 定版模型、同一提示词版本、同一预算上限、同一 `reflect` strategy。唯一自变量是是否启用该适配器；纯 Web 组禁用它，适配器组启用它并保留既有失败降级行为。

两组须交替执行并尽量置于相近时间窗，记录各组起止时间、模型 ID、提示词版本、预算、索引版本/哈希、robots/许可核验时间、缓存状态以及完整事件轨迹。网页内容、搜索排序与缓存均可能变化，不能把这些变化归因于适配器。任何改善案例的归因都必须先核对事件轨迹。

## 6. 报告承诺

实验结果将给出逐题 × 两组 × 两个主指标及全部辅助指标的对照表、效应量、标注分歧和事件轨迹依据。结论将机械对照本文件的阈值，并明确写出：“初步观察，不构成统计证明”。不得在实验后替换指标、样本、阈值或候选定义。
